# Jogo da Vida (Conway's Game of Life) - C++

## Descrição
Implementação do Jogo da Vida em C++. O projeto foi estruturado seguindo o padrão **MVC (Model-View-Controller)** para manter o código modular e organizado, demonstrando boas práticas de design de software em C++.

## Tecnologias
* C++
* Padrão Arquitetural MVC
